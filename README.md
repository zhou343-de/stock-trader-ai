### 选股流水线

```
stock_screener.py ─── 四层漏斗过滤
    │                  ① 基本面过滤（PE/市值/成交额）
    │                  ② 多因子预排序（非纯涨幅排序）
    │                  ③ 技术验证（均线/MACD/量比/放量 ≥ 2/4）
    │                  ④ 流动性检查（滑点 ≤ 0.5%）
    ▼
factor_scorer.py ──── 多维度因子评分
    │                  ⑤ 10 个基础因子（动量/量能/均线/MACD/RSI...）
    │                  ⑥ 27 个增强因子（KDJ/布林带/OBV/CCI...）
    │                  ⑦ 板块轮动加分（行业排名加权）
    ▼
AI 决策层 ──────────── 智能选股
    │                  ⑧ 综合评分 × 市场环境 × 行业轮动
    │                  ⑨ 从 Top 5 中选 2-3 只，行业互补
    ▼
simulate_trend.py ─── 交易执行 + 风控管理
                       ⑩ 下单 → 持仓监控 → 止盈止损 → 平仓
```

## 🛡️ 八层风控体系

> **设计理念：** 活下来比赚钱重要。八层防护从组合级到个股级，层层递进。

| 层级 | 机制 | 触发条件 | 执行动作 |
|:---:|:---|:---|:---|
| **P0** | 组合回撤熔断 | 峰值总资产回撤 ≥ 10% | 全部清仓 + 冻结交易 3 个交易日 |
| **P0** | 移动止盈 | 浮盈曾达 ≥ 10% 后回落至最高浮盈的 50% | 全部卖出锁定利润 |
| **P1** | ATR 动态止损 | 止损 = -1.5 × 20日ATR / 买入价 | 高波动自动放宽止损空间 |
| **P1** | 分级止盈 | TP1 / TP2 / TP3（环境自适应） | 分三档各减仓 1/3 |
| **P1** | 防踩踏 + 指数熔断 | ≥50% 持仓跌 > 3% 或上证跌 ≥ 3% | 暂停买入 + 收紧止损至 -3% |
| **P2** | 持仓天数管理 | 持有 ≥ 20 天且浮盈未达 TP1 | 强制平仓释放资金 |
| **P2** | 跌停封板检测 | 开盘一字跌停（当前价=跌停价 且 卖一为0） | 告警邮件 + 次日优先处理 |
| **P2** | 持仓相关性监控 | 任意两只持仓皮尔逊相关系数 ≥ 0.7 | 分散化警告 + 换股建议 |

### 止盈参数（市场环境自适应）

| 环境 | 止损 | TP1 | TP2 | TP3 | 最大仓位 | 最多持仓 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 🐂 牛市 | -8% | 15% | 25% | 35% | 90% | 4 只 |
| 📊 震荡 | -7% | 15% | 25% | 35% | 85% | 3 只 |
| 🐻 熊市 | -4% | 10% | 18% | 25% | 60% | 2 只 |

## 📊 量化因子系统

### 基础因子（10 个）

| 因子 | 权重 | 说明 |
|:---|:---:|:---|
| change_pct | 25 | 涨跌幅 |
| volume_ratio | 20 | 量比 |
| ma_aligned | 20 | 均线多头排列 |
| macd_signal | 15 | MACD 信号 |
| turnover | 10 | 换手率 |
| amount | 10 | 成交额 |
| relative_strength | 20 | 相对强度 |

### 增强因子（27 个）

| 类别 | 因子 | 说明 |
|:---|:---|:---|
| **多周期动量** | momentum_5d / 10d / 20d / 60d | 各周期涨幅 + 动量加速度 |
| **波动率结构** | upside_vol / downside_vol | 上行 vs 下行波动率比 |
| **量价背离** | vol_price_divergence | 价涨量缩 / 放量探底检测 |
| **KDJ** | kdj_k / d / j + signal | 金叉 / 死叉 / 超买超卖 |
| **布林带** | boll_pct_b + bandwidth | 价格在布林带中的位置 |
| **OBV** | obv_direction + trend | 能量潮趋势方向 |
| **多周期RSI** | rsi_7d / 14d / 28d + combo | RSI 组合信号 |
| **价格位置** | price_position_60d | 距 60 日高低点位置 |
| **成交额集中度** | volume_concentration | 5日 / 20日均量比 |
| **支撑阻力** | support / resistance_distance | 距支撑位 / 阻力位距离 |
| **威廉指标** | williams_r | 超买超卖判断 |
| **CCI** | cci | 顺势指标 |
| **相对强弱** | rs_vs_index_20d | 个股 vs 大盘强弱 |
| **均线距离** | price_vs_ma20 / ma60 | 价格偏离均线程度 |

### 因子权重自进化

```
每周五 16:00 自动执行：
  ① 收集最近 20 笔已完成交易
  ② 过滤污染样本（熔断/超时平仓等系统性交易）
  ③ 计算各因子贡献与收益的相关性
  ④ 贡献高的 +2，贡献低的 -2
  ⑤ 每周向初始值回归 3%（防漂移）
  ⑥ 边界检查：确保每个因子在 [5, 40] 范围
```

## 🕐 自动调度

| 时间 | 任务 | 说明 |
|:---|:---|:---|
| 周一-五 09:30, 09:50 | 早盘盯盘 | 回撤熔断 / 移动止盈 / ATR止损 |
| 周一-五 09:45 | 开盘建仓 | 空仓触发，延后 15 分钟避开开盘波动 |
| 周一-五 10:00-11:40 | 智能盯盘 | 每 20 分钟（6 次） |
| 周一-五 13:00-14:40 | 午后盯盘 | 每 20 分钟（6 次） |
| 周一-五 15:10 | 尾盘风控 | 只卖不买 |
| 周一-五 15:30 | 收盘日报 | 含夏普 / 基准 / 回撤 / 相关性矩阵 |
| 周一-五 16:00 | 健康检查 | 验证日报 / 账户 / 快照，异常邮件告警 |
| 周五 16:00 | 周度策略优化 | 因子权重自进化 + 回测验证 |

> 📅 **交易日历：** 自动识别法定节假日（30 天）和调休交易日（3 天），非交易时段 Cron 任务自动跳过。

## 🚀 快速开始

### 环境要求

- Python 3.11+
- curl（系统自带）

### 安装

```bash
git clone https://github.com/yourname/stock-trader-ai.git
cd stock-trader-ai
```

### 初始化账户

```bash
# 初始化 10 万虚拟资金
python3 scripts/simulate_trend.py init 100000

# 查看账户状态
python3 scripts/simulate_trend.py status
```

### 查看市场环境

```bash
python3 scripts/market_regime.py
```

### 量化选股

```bash
# 四层漏斗筛选 Top 10 候选
python3 scripts/stock_screener.py --top 10 --max-price 20 --json

# 因子评分 Top 5
python3 scripts/stock_screener.py --top 10 --json | \
  python3 scripts/factor_scorer.py --top 5 --json
```

### 手动交易

```bash
# 买入
python3 scripts/simulate_trend.py buy sz002475 立讯精密 500 64.50 \
  --reason "因子评分82分，电子半导体板块，技术面多头排列"

# 卖出
python3 scripts/simulate_trend.py sell sz002475 500 66.00

# 查看持仓
python3 scripts/simulate_trend.py status
```

### 风控检查

```bash
# 回撤熔断检查
python3 scripts/simulate_trend.py circuit_breaker_check

# 更新 ATR 止损
python3 scripts/simulate_trend.py update_atr_stops

# 查看 A 股交易规则
python3 scripts/simulate_trend.py rules
```

### 邮件配置（可选）

```bash
cp config/smtp.env.example config/smtp.env
# 编辑 config/smtp.env，填入你的邮箱配置
```

## 🧪 回测引擎

内置日K线级全流程回测，覆盖选股 → 评分 → 交易 → 风控完整链路。

```bash
# 回测 2026 年 Q1
python3 scripts/backtest.py --start 2026-01-05 --end 2026-03-31 --json

# 自定义初始资金
python3 scripts/backtest.py --start 2026-01-05 --end 2026-04-25 --cash 200000
```

**输出指标：**
- 累计收益率 / 年化收益率
- 最大回撤
- 夏普比率
- 胜率 / 盈亏比
- 每笔交易明细

## ⚙️ A 股铁律（硬编码）

系统内置 A 股交易规则，无需手动配置：

| 规则 | 说明 |
|:---|:---|
| T+1 | 买入当日不可卖出 |
| 100股取整 | 主板/创业板 100 股起，科创板 200 股起 |
| 涨跌幅限制 | 主板 ±10%，创业板 ±20%，ST ±5% |
| 价格笼子 | 主板 ±2% 且 ±0.10 元，创业板 ±2% |
| 交易费用 | 佣金万3（最低5元）+ 过户费 0.001% + 印花税 0.05% |
